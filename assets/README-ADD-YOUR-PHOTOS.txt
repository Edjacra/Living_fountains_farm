LIVING FOUNTAINS FARM — WHERE TO ADD YOUR REAL PHOTOS
=======================================================

Every image below is currently a placeholder (a plain colour card with
the product name printed on it) so the site looks and works correctly
right now. To swap in your real photos, just replace the file at the
exact same path with your photo, using the EXACT same file name
(keep the .jpg extension, or change every reference to it in the
matching .html file if you use a different format).

Recommended photo size: square, at least 800x800px for produce/
product photos, and 1200x800px (landscape) for the factory people
photos.
